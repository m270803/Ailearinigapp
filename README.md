# Ailearinigapp
An AI-powered educational platform designed to enhance student learning through document-to-knowledge transformation.

Tech Stack: React 19 (Vite), Node.js (Express 5), MongoDB (Mongoose), Google Gemini 1.5-Flash API, Tailwind CSS 4.

AI Integration: Developed an intelligent chat system using Google Gemini 1.5-Flash to provide context-aware document explanations and summaries.

Custom RAG Pipeline: Engineered a Retrieval-Augmented Generation (RAG) system featuring a custom text-chunking algorithm with keyword-based relevance scoring to provide precise context to the LLM and minimize hallucinations.

Automated Content Generation: Built background processing workflows using PDF-parse and Multer to extract text from academic PDFs, automatically generating interactive flashcards and multiple-choice quizzes.

Secure Infrastructure: Implemented robust user authentication using JWT and Bcrypt, ensuring secure document storage and personalized learning progress tracking.

Modern UI/UX: Designed a responsive, high-performance interface with Tailwind CSS 4, featuring real-time markdown rendering and code syntax highlighting for technical study materials.
